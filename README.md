# Новогодняя открытка 2026

Интерактивная новогодняя открытка с CSS‑анимациями: падающий снег поверх всех блоков и орбитальное движение элементов.

## Стек
- HTML5
- CSS3 (чистый CSS, без препроцессоров)
- VS Code

## Особенности
- Снег реализован через `@keyframes` и `position: absolute`, идёт поверх всех слоёв.
- Элементы двигаются по кругу с помощью `offset-path` и `offset-distance`.
- Адаптивная вёрстка: медиа‑запрос `max-width: 450px`.

## Запуск
1. **Локально:** откройте `index.html` в браузере. Стили уже готовы в CSS — ничего компилировать не нужно.
2. **Через GitHub Pages:** проект размещён на GitHub Pages — откройте ссылку вида `https://github.com/AlexGukov44/New-Year-card-2026`, чтобы увидеть открытку в браузере.
